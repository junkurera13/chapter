# Daily log

This is Chapter's concise, factual record of completed work. Each day is
audited against repository and deployment evidence before an entry is written.

Entries use four sections:

- **Done:** verified outcomes from the day.
- **Learned or decided:** decisions that change how Chapter should be built.
- **Still open:** relevant unfinished work, without silently carrying it into
  tomorrow.
- **Tomorrow starts with:** one concrete next action.

`TODAY.md` is rewritten at the start of a day. This file is append-only except
when correcting or completing the current day's entry.
